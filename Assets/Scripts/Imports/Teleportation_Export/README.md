# Teleportation System (Hiraishin)

This folder contains the core scripts for the teleportation system implemented in the Unity FPS project.

## Files included:
- **HiraishinManager.cs**: The main controller for marked-based teleportation.
- **HiraishinKunai.cs**: Logic for the projectile that marks teleportation spots.
- **HiraishinMark.cs**: Logic for the visual/logical mark left by the Kunai.
- **TeleportPlayer.cs**: Utility script for character teleportation.

## Usage
These scripts are designed for the Minato-style Hiraishin teleportation system where a player throws a kunai and can instantly teleport to its location.
